# Word Guess - Quick Start Guide

## 🚀 Getting Started (30 seconds)

1. **Open the game**: Open `index.html` in your web browser
2. **Pick a level**: Choose Level 1, 2, or 3 from the menu
3. **Read the goal**: Find all correct words without losing 3 hearts ❤️

## 🎮 Basic Controls

### Two Modes (Switch anytime)

**✓ Select Correct Mode** (Green button)
- Tap words you think are correct
- ✅ Right = word stays green
- ❌ Wrong = lose 1 heart ❤️

**✗ Mark Wrong Mode** (Red button)  
- Tap words you think are wrong (they turn red)
- No penalty for marking
- Tap again to unmark
- Marked words can't be selected

### Using Hints

1. Tap any hint button (e.g., "Animal", "Red")
2. Numbers appear on the button showing correct/wrong matches
3. Watch the star tracker update as you use hints
4. Fewer hints = more stars ⭐

### Star Tracker

At the top of the screen you'll see:
- **Current Rating**: Your stars based on hints used so far
- **Hints Remaining**: How many more hints you can use for each star level

## 🎯 Goal

- **Win**: Select ALL correct words
- **Lose**: Run out of hearts (3 mistakes)
- **Stars**: Based on hints used (fewer = better)

## 💡 Strategy Tips

1. **Start with Mark Mode**: Mark obvious wrong answers first
2. **Use broad hints first**: Like "Animal" before "Mammal"  
3. **Cross-reference hints**: Combine info from multiple hints
4. **Be strategic**: Mark wrong words safely, only select when sure

## Example Game

**Level 1: Animals & Birds**

Words shown: `Salmon`, `Dog`, `Eagle`, `Cat`, `Parrot`, `Rose`, `Car`

**Step 1**: Tap "Animal" hint → Button shows "✓4 ✗1"
- So 4 of the 7 words are correct animals
- But there's 1 wrong word that might seem like an animal
- Star tracker updates: "4 hints left for 3★"

**Step 2**: Tap "Mammal" hint → Button shows "✓3 ✗0"
- 3 mammals are correct
- This helps narrow down which animals
- Star tracker: "3 hints left for 3★"

**Step 3**: Notice "Rose" and "Car" aren't animals
- Switch to Mark Mode
- Mark "Rose" and "Car" as wrong (they turn red)

**Step 4**: Use "Bird" hint → Shows "1 correct, 1 wrong"
- 1 bird is correct, 1 is wrong
- Parrot and Eagle are birds
- Need more info to know which

**Step 5**: Make educated guesses
- Select "Dog" and "Cat" (mammals, safe choices)
- Select "Salmon" (the fish)
- Now need to pick between Parrot and Eagle

**Step 6**: Use another hint or take a chance
- 1 heart lost if wrong
- 2 hearts remaining for mistakes

## 🎨 Level Editor Quick Start

Want to make your own level?

1. Click "📝 Level Editor" from main menu
2. Add some correct words (the answers)
3. Add some wrong words (the traps)
4. Create hints by checking boxes next to matching words
5. Click "👁️ Preview Level" to test it
6. Click "💾 Export JSON" to save it

## 📱 Mobile Tips

- Play in portrait mode (vertical)
- Use two thumbs for faster play
- The hint panel scrolls left/right
- All buttons are big enough for fingers

## ⭐ Star Ratings

**Level 1**:
- ⭐⭐⭐ = 5 hints or less
- ⭐⭐ = 6-8 hints
- ⭐ = 9-12 hints

**Challenge yourself**: Try to beat levels with fewer hints!

## 🐛 Troubleshooting

**Game won't load?**
- Make sure JavaScript is enabled
- Try a different browser (Chrome/Firefox/Safari)
- Clear cache and reload

**Progress not saving?**
- Allow cookies/localStorage
- Don't use incognito/private mode

**Words not responding?**
- Make sure you're not tapping too fast
- Try tapping the center of words
